# AUREN CONTRACTS
### Furniture for Spaces That Work.

A modern, luxury-inspired commercial furniture website concept built with Next.js, TypeScript, and Tailwind CSS.

Designed to demonstrate how a commercial furniture brand can present its collections, services, and industry-specific furnishing solutions through a refined digital experience.

## Project Overview

AUREN CONTRACTS is a conceptual website for a premium commercial furniture supplier.

The project focuses on combining visual storytelling, structured content, responsive layouts, and interactive components to create a professional digital presence.

The website is designed around a quiet-luxury aesthetic, featuring neutral colors, refined typography, carefully selected interior imagery, and subtle motion effects.

## Key Features

- **Modern Homepage:** Editorial-style hero section and structured brand presentation.
- **Furniture Collections:** Organized furniture categories with interactive collection cards.
- **Service Showcase:** Dedicated sections for furniture supply, transportation, installation, assembly, and project coordination.
- **Industry Solutions:** Six dedicated industry categories with individual gallery pages.
- **Project Showcase:** Conceptual commercial furnishing projects.
- **Responsive Design:** Layouts designed for desktop, tablet, and mobile screens.
- **Smooth Animations:** Subtle reveal animations and interactive transitions.
- **Contact Interface:** Demonstration contact page and form.

## Getting Started

Follow these instructions to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/MahamHayatDev/auren-contracts.git
```

### 2. Navigate to the Project

```bash
cd auren-contracts
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

```text
http://localhost:3000
```

## Deployment

The project is designed for deployment on Vercel.

Deployment workflow:

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Select the Next.js framework preset.
4. Deploy the application.
5. Access the published website through the generated deployment URL.
